## What's new

### Added
- feat(player): audio conversion built into the app - movies and episodes with E-AC3, AC3, DTS or TrueHD audio (which the webview can't decode) now play with sound. HEVC video is converted too when needed
- feat(player): the file is checked before playback starts, so a title that needs conversion begins with sound from the first second instead of playing silently
- feat(home): redesigned home screen with a hero banner, Continue Watching and a Live TV row
- feat(i18n): every screen is fully translated (pt, en, es, fr, de, it), including genre tags
- feat(tmdb): TMDB metadata is always on; the key is built into the app and is not shown or editable

### Fixed
- fix(home): Continue Watching shows one card per movie and one per series, using the furthest episode watched
- fix(player): audio no longer plays late after conversion, including when resuming mid-file
- fix(subtitles): subtitles show up in converted playback and sit higher above the bottom edge
- fix(epg): the TV Guide shows programmes for Xtream-panel M3U playlists with no EPG address, with no overlapping entries
- fix(ui): the browser right-click menu is disabled (kept only in text fields)

### Changed
- chore(build): ffmpeg (GPLv3 build) is bundled with the app and downloaded at build time with a SHA-256 check; the installer is larger as a result
